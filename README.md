# 💰 Brutto-Netto-Gehaltsrechner

Ein moderner und benutzerfreundlicher Gehaltsrechner für Schüler und junge Arbeitnehmer. Schnell und einfach das Nettoeinkommen berechnen!

## 🎯 Features

- ✅ **Schnelle Berechnung** - Bruttogehalt eingeben und sofort berechnen
- ✅ **Detaillierte Aufschlüsselung** - Alle Abzüge im Überblick
- ✅ **Modernes Design** - Ansprechendes UI speziell für Schüler (17-19 Jahre)
- ✅ **Responsive** - Funktioniert auf Handy, Tablet und Desktop
- ✅ **Offline-Funktion** - Keine Internetverbindung nötig nach dem Laden

## 📋 Berechnungsgrundlagen

Der Rechner berechnet das Nettoeinkommen basierend auf folgenden Parametern:

### Persönliche Parameter
- **Steuerklasse**: 1
- **Religionszugehörigkeit**: Keine Kirchensteuer
- **Alter**: Unter 23 Jahren
- **Kinder**: Keine

### Abzüge

#### Sozialversicherung (Arbeitnehmeranteil)
- **Krankenversicherung**: 7,3% + 2,7% Zusatzbeitrag = 10,0%
- **Rentenversicherung**: 9,3%
- **Pflegeversicherung**: 3,05%
- **Arbeitslosenversicherung**: 2,6%

#### Einkommensteuer
- Berechnet nach deutschem Steuertarif 2026
- Mit Grundfreibetrag (€11.600)
- Progressionszonenberechnung
- Solidaritätszuschlag (5,5% auf ESt, ab €972)

## 🚀 Verwendung

1. Bruttogehalt eingeben
2. Auf "Berechnen" klicken (oder Enter drücken)
3. Ergebnisse ansehen und alle Abzüge im Detail nachvollziehen

- **CSS3** - Modernes Design mit Animationen und Farbverläufen
- **JavaScript (Vanilla)** - Keine Dependencies, pure Berechnung

## 📄 Lizenz

Frei verwendbar

## ⚠️ Hinweis

Dieser Rechner bietet eine Näherung. Für offizielle Berechnungen und genaue Steuererklärungen konsultiere bitte:
- Deinen Arbeitgeber
- Einen Steuerberater
- Das Finanzamt
- Die offizielle Lohnsteuerhilfe

Die Berechnung berücksichtigt nicht:
- Besondere Freibeträge
- Werbungskosten
- Sonderausgaben
- Besonderheiten einzelner Bundesländer
